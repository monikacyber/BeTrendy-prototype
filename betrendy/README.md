# BeTrendy — пакет переноса

Источник: https://betrendy.space/ (Хорошоп). Снимок: 13.11.2026, Asia/Dubai.

Целевой WordPress на Hostinger: https://betrendy.online/.
Первоначальный технический адрес: https://snow-anteater-890728.hostingersite.com/.
Отдельный репозиторий: https://github.com/monikacyber/BeTrendy-prototype.

## Состояние переноса

Импорт завершён и проверен внутри WordPress 13.11.2026: 61 товар, 17 категорий, 6 страниц и 2 статьи, 246 изображений. Товары и контент созданы **черновиками**. Проверка всех SKU, цен, галерей, привязок к категориям, файлов изображений и структуры блоков дала 0 расхождений. Отчёт: `data/wordpress-import-verification.json`, карта созданного контента: `data/wordpress-content-map.json`.

[Предпросмотр главной](https://betrendy.online/?page_id=333&preview=true) доступен после входа редактором в этот WordPress; [редактирование главной](https://betrendy.online/wp-admin/post.php?post=333&action=edit). Главная использует шаблон `home-preview`; в её авторизованном предпросмотре отображаются импортированные черновики товаров. Это ещё не запущенный магазин.

Тема BeTrendy, WooCommerce, Jetpack и плагины импорта/исходных URL активны. Установлен исходный логотип, язык сайта — украинский, служебные страницы WooCommerce названы по-украински. В шапке отключено автоматическое добавление дублирующих значков WooCommerce после каждого меню; используются явные ссылки корзины и кабинета. Фильтр: [официальный Block Hooks API](https://developer.wordpress.org/reference/hooks/hooked_block_types/).

Шаблоны товара и каталога используют штатные редактируемые блоки установленного WooCommerce 11.3.0 с общими отступами темы и украинскими подписями. Шрифт Geologica задан также для товарных страниц. [Иерархия шаблонов WooCommerce](https://developer.woocommerce.com/docs/theming/block-theme-development/template-hierarchy/).

## Что сохранено

- `source/pages/` — содержимое и метаданные 276 публичных адресов; три языка. Все 271 адрес из первоначальной карты сохранены. Из дополнительных адресов полного списка категорий 13 возвращают проверку браузера; их перечень есть в `data/capture-report.json`. Содержимое таких списков целиком не подтверждено.
- `data/catalog.json` — 61 уникальный SKU в каждой из трёх языковых версий; исходные цены, валюты, составы, характеристики, галереи и URL.
- `data/pages.json` — главная, пять информационных страниц и две статьи в каждом языке, в редактируемых блоках WordPress.
  У двух статей исходные RU/EN страницы не содержат текста: четыре пустые записи отмечены отдельно; перевод не выдумывался.
- `data/categories.json` — 17 категорий в каждом языке, с иерархией.
- `data/woocommerce-products-uk.csv` — украинский каталог в гривнах, 61 товар **в статусе черновик**.
- `assets/` и `data/media-manifest.json` — оригинальные изображения с SHA-256. GitHub Actions загружает недостающие файлы и проверяет их контрольные суммы.
- `wordpress/themes/betrendy/` — блоковая тема с цветами, шрифтом, структурой меню и контактами исходника.
- `wordpress/plugins/betrendy-urls/` — сохранение исходных адресов товаров/категорий и метаданных SEO после импорта.
- `scripts/import-wordpress.php` — импорт через WP-CLI из локального пакета, только в отдельный сайт BeTrendy. Повторный запуск пропускает имеющиеся SKU/страницы.
- `wordpress/plugins/betrendy-import/` — импорт через подключённый Jetpack, с небольшими возобновляемыми партиями и закрытым для посетителей статусом. Полные данные собираются локально в защищённые PHP-файлы; эта папка данных исключена из GitHub.

Архив охватывает обнаруженные публичные страницы. Личные кабинеты, покупатели, пароли, платежные настройки и история заказов не доступны через публичный сайт и не включены. Полнота скрытого каталога может быть проверена только выгрузкой из админки Хорошопа.

## Развёртывание

1. На отдельном WordPress установить WooCommerce и настроить валюту UAH. Установить тему `betrendy` и плагин `betrendy-urls` из ZIP-пакетов или каталогов.
2. Загрузить каталог `betrendy` на сервер через Hostinger File Manager/SFTP. Он должен содержать `data`, `assets` и `scripts`. Не размещать служебный пакет в публично доступной папке, если позже в него будут добавлены непубличные сведения.
3. В корне WordPress выполнить:

```sh
wp eval-file /absolute/path/to/betrendy/scripts/import-wordpress.php /absolute/path/to/betrendy https://betrendy.online
```

Скрипт проверяет целевой адрес и валюту, создаёт товары, страницы и статьи **черновиками**, импортирует локальные изображения и сохраняет RU/EN как исходные данные перевода. Он не включает оплату и не меняет DNS.

Альтернатива для каталога: **Товары → Импорт → woocommerce-products-uk.csv**. CSV использует исходные внешние URL изображений; при блокировке скачивания со стороны Хорошопа использовать WP-CLI с локальными `assets/`.

## Что ещё нужно перед запуском

- Выбрать публикацию и настроить главную: сейчас контент остаётся черновиками, главная не назначена публичной стартовой страницей, магазин не запущен.
- Настроить многоязычность. RU/EN сохранены, но архив переводов сам по себе не создаёт работающие языковые витрины. Не импортировать три версии как независимые товары с повторяющимися SKU.
- Английский источник использует USD, украинский/русский — UAH. Выбрать поведение валют и платежей до публикации.
- Создать страницу списка статей, настроить языковые меню и проверить каждую ссылку. Ссылки `/ru/`, `/en/` и `/blog/` ещё не ведут на готовые витрины/список; ссылки на черновики также не предназначены для посетителей. В публичном режиме товарные блоки показывают только опубликованные товары, в авторизованном предпросмотре главной — импортированные черновики.
- Настроить доставку, оплату, налоги и письма в соответствии с текущими настройками действующего магазина; протестировать оформление заказа.
- Сверить актуальные цены, акции и остатки непосредственно перед запуском. В снимке нет точных складских количеств и сроков окончания акций.
- Импортировать отзывы/заказы/клиентов из админки Хорошопа при необходимости. Публичные тексты отзывов, если присутствовали, остаются в архиве страницы, но автоматически не создаются как новые WooCommerce отзывы.
- Провести проверку на desktop/mobile и согласовать переключение основного домена.

## Проверка и повторное сохранение

```sh
python3 -m pip install beautifulsoup4
python3 betrendy/scripts/capture.py
python3 betrendy/scripts/prepare.py
python3 betrendy/scripts/restore_media.py
```

Сценарии сбора ограничены публичным доменом источника и изображениями `uniksshop.com`, на которые ссылается исходник. Они не выполняют JavaScript страниц. `restore_media.py` сохраняет только файлы с совпадающей контрольной суммой и сообщает о несовпадениях; в GitHub уже сохранены все 389 локальных оригиналов. Импортёр WordPress использует закреплённый коммит GitHub и проверяет SHA-256 каждого изображения.

Формат CSV проверен по [официальной документации WooCommerce](https://woocommerce.com/document/product-csv-importer-exporter/). PHP-синтаксис и сериализация блоков проверяются локально; это не заменяет проверку внутри установленного WordPress/WooCommerce.

## Публичная копия без платёжных реквизитов

Это очищенный экспорт для публичного GitHub. Из текстов, HTML, JSON и CSV удалены банковские счета (IBAN), банковские коды/названия, данные получателя оплаты и его личный налоговый идентификатор. В местах удаления используется маркер `[PAYMENT DETAILS OMITTED]`. Рабочие телефоны, email и адрес магазина сохранены.

Полные исходники и данные для импорта в WordPress остаются локально; архивы в `betrendy/packages/` не входят в этот публичный экспорт. Перед запуском магазина нужно сверить юридические и платёжные страницы с полным локальным пакетом и актуальными данными владельца. Публичную копию платёжных/юридических страниц с пропусками нельзя считать готовой к публикации на рабочем сайте.

Сгенерированные deployment-данные `betrendy/wordpress/plugins/betrendy-import/data/` также исключены: они дублируют данные импорта и могут содержать полный локальный платёжный текст. Код плагина и `scripts/package-import-plugin.py` сохранены. При сборке из этого публичного репозитория используйте очищенные `betrendy/data/`; сборщик создаст payload и контрольные суммы заново.

Для следующих обновлений GitHub сначала запускайте `python3 betrendy/scripts/public_export.py` и используйте только результат в `betrendy/.cache/github-public/`. Не переносите неочищенные локальные `source/`, `data/` или копии данных внутри плагинов напрямую в публичный репозиторий.
